# Support Policy & Diagnostic Reports

If you encounter issues with Antigravity for Home Assistant:

1. Run `$ha-feedback bug` inside the App terminal to generate a sanitized diagnostic report.
2. Review the output to ensure no secrets or private keys are included.
3. Open an issue on [GitHub Issues](https://github.com/Kanu-Coffee/antigravity-for-home-assistant/issues).

Security concerns should be submitted privately according to `.github/SECURITY.md`.
